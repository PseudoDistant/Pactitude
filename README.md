# Pactitude!
I'm a small scale server administrator. I constantly work with multiple different Linux distributions (primarily Debian-based systems), but I use Arch Linux on my various home desktops and laptops...\
It's very annoying having to use apt on multiple machines, and then accidentally typing `sudo apt upgrade` on your Arch system because of the disconnect.\

### So I created this tool to help!
![Pactitude running on Raspberry Pi OS (over SSH)](https://github.com/user-attachments/assets/420c7063-ba7b-4cc6-8f6a-ede93da995c4)

# What is Pactitude?
Pactitude is a (WIP) wrapper for Apt (and later other package managers) that takes Pacman arguments! Essentially allowing you the Pacman experience no matter what Oracle wants you to use!
